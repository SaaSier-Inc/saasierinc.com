## Core angle

MockForge shipped major protocol expansions through the summer — stable GraphQL subscriptions and WebSocket event streaming, gRPC bidirectional streaming record-and-replay, and RAG-based AI data synthesis. Beta program opens this quarter.

## LinkedIn post

```text
MockForge shipped some big milestones over the summer. Here's what landed:

GraphQL subscription simulation and WebSocket event streaming — both stable. Teams testing event-driven architectures can define multi-message sequences with varying payload shapes, timing, and error scenarios without a real backend.

gRPC bidirectional streaming record-and-replay. This was a recurring pain point for teams doing integration testing of streaming RPC services. You could mock unary calls, but stateful bidirectional streams required either a real peer or a hand-rolled test server. Not anymore.

AI data synthesis with RAG-based context-aware field inference. Instead of generating random-but-plausible data, the engine references existing schemas, payloads, and context documents to infer field distributions and value ranges.

Beta program is finalized and onboarding opens this quarter. Early access to admin UI, AI synthesis, and full protocol simulation. Beta configs carry through to public launch.

Full update:
```
